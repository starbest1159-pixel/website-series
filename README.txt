Bannlai Series – Separate UI Assets

Each PNG is a separate crop from the generated high-resolution asset sheet, plus the original full-size character illustration. Crops retain their native pixel dimensions; they have not been artificially enlarged. Some items are grouped crops (for example, action buttons and platform buttons) because individual button shapes are tightly packed in the source sheet.

For production use, use the logo, character art, banner and mascot as separate image assets. UI controls such as buttons, badges and icons are best recreated as HTML/CSS/SVG where crisp scaling and accessibility are required.
